## Kesimpulan Perjalanan Belajar Pertemuan 1–13

Perjalanan pembelajaran **Pengantar Data Science** dari Pertemuan 1 sampai Pertemuan 13 memberikan pemahaman yang bertahap mengenai bagaimana data diolah hingga dapat menghasilkan informasi, prediksi, dan insight yang bermanfaat. Pada tahap awal, pembelajaran dimulai dari pengenalan Data Science, alur kerja **CRISP-DM**, serta penggunaan Python, Google Colab, dan GitHub sebagai lingkungan kerja. Pemahaman tersebut kemudian diperkuat melalui struktur data Python, NumPy, dan Pandas sehingga proses membaca, memilih, memanipulasi, serta mengelompokkan data dapat dilakukan secara lebih sistematis.

Tahap berikutnya menunjukkan bahwa kualitas hasil analisis sangat bergantung pada kualitas data yang digunakan. Materi **data cleaning** mengajarkan penanganan missing values, data duplikat, outlier, serta pengambilan data dari JSON dan API. Setelah data lebih bersih, statistika deskriptif dan analisis data digunakan untuk memahami karakteristik, distribusi, serta hubungan antarvariabel. Visualisasi dengan Matplotlib dan Seaborn kemudian membantu mengubah hasil analisis menjadi informasi yang lebih mudah dibaca dan dikomunikasikan. Dari bagian ini, saya memahami bahwa Data Science tidak hanya tentang menghasilkan angka, tetapi juga tentang menjelaskan makna dari data secara jelas dan dapat dipahami.

Sebelum membangun model Machine Learning, data juga harus dipersiapkan dengan benar melalui **encoding, feature scaling, train-test split**, dan pencegahan **data leakage**. Tahap ini menjadi dasar penting ketika pembelajaran berlanjut ke Machine Learning. Pada regresi linear, saya mempelajari bagaimana model digunakan untuk memprediksi nilai kontinu dan bagaimana performanya dievaluasi menggunakan MAE, RMSE, dan R². Selanjutnya, pada klasifikasi, saya mempelajari Logistic Regression, Decision Tree, Random Forest, Confusion Matrix, Accuracy, Precision, Recall, dan F1-Score. Dari materi klasifikasi juga terlihat bahwa pemilihan metrik evaluasi harus menyesuaikan konteks masalah. Pada data yang tidak seimbang seperti customer churn, Accuracy saja dapat memberikan kesimpulan yang menyesatkan sehingga Recall, Precision, dan F1-Score perlu diperhatikan.

Pembelajaran kemudian berkembang dari **Supervised Learning** menuju **Unsupervised Learning**. Melalui K-Means dan Hierarchical Clustering, saya memahami bagaimana pola dan kelompok dapat ditemukan pada data tanpa label, termasuk penggunaan Elbow Method dan Silhouette Score untuk membantu mengevaluasi hasil clustering. Materi Association Rule Mining dengan algoritma Apriori memperluas pemahaman mengenai pola keterkaitan antaritem melalui Support, Confidence, dan Lift. Konsep tersebut kemudian dihubungkan dengan sistem rekomendasi menggunakan pendekatan Collaborative Filtering dan Content-Based Filtering.

Pada bagian akhir, pembelajaran memperkenalkan **Deep Learning** dan **Natural Language Processing (NLP)** sebagai pengembangan lebih lanjut dari konsep Machine Learning. Artificial Neural Network memberikan gambaran mengenai bagaimana neuron, layer, weight, bias, dan activation function bekerja dalam mempelajari pola non-linear. Sementara itu, NLP menunjukkan bagaimana data teks dapat diubah menjadi representasi numerik menggunakan TF-IDF dan digunakan untuk melakukan analisis sentimen. Materi ini memberikan gambaran bahwa konsep-konsep dasar yang dipelajari sejak awal menjadi fondasi untuk memahami teknologi AI yang lebih kompleks.

Secara keseluruhan, rangkaian pembelajaran ini membuat saya memahami bahwa proses Data Science merupakan sebuah **pipeline yang saling terhubung**, mulai dari memahami masalah, memperoleh dan membersihkan data, melakukan eksplorasi dan visualisasi, menyiapkan data, membangun model, mengevaluasi hasil, hingga menginterpretasikan temuan. Hal terpenting yang saya pelajari adalah bahwa model yang kompleks tidak selalu menjadi bagian utama dari Data Science. Kualitas data, ketepatan metode, pemilihan metrik evaluasi, serta kemampuan menjelaskan hasil justru sangat menentukan apakah analisis yang dilakukan benar-benar dapat digunakan untuk membantu pengambilan keputusan.
